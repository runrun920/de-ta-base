【実行手順】
1. ターミナルでダウンロード
   git clone https://github.com/runrun920/de-ta-base.git
   cd de-ta-base

2. 必要なライブラリを入れる
   pip3 install pandas openpyxl

3. プログラムを実行
   python3 merge_to_master.py

無事に「fe_study_master.xlsx」と「fe_study_master.csv」が作られたか確認してみて！
